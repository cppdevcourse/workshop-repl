# Практикум 'REPL'

В этом практикуме необходимо будет, используя и дорабатывая
готовую библиотеку для REPL*)-приложений, разработать
приложение для работы со строками.

*) - REPL (Read-Evaluate-Print Loop) - интерактивная среда программирования
в командной строке, которая позволяет вводить код, немедленно его
выполнять (вычислять) и видеть результат в цикле.

## Обзор проекта

Проект состоит из header-only библиотеки `repl`, исходный код
которой находится в файлах:
- repl.hpp
- argument_parsers.hpp
- command.hpp

и двух приложений: калькулятора (calculator.cpp) и приложения
для работы со строками (strings.cpp).

Калькулятор демонстрирует, как использовать код библиотеки
`repl`; в задании его также нужно будет доработать.

Приложение для работы со строками нужно разработать в этом
задании.

### Приложение `strings`

В текущей реализации REPL для приложения `strings` поддерживает
только две встроенные команды:
- `exit`,
- `help`.

Необходимо добавить следующие команды:

- Конкатенация строк.<br>
  Короткое имя: `ct`.<br>
  Полное имя: `concat`.<br>
  Аргументы: `std::string`, `std::string`.<br>
  Возвращаемое значение: `std::string`.

- Поиск символа в строке.<br>
  Короткое имя: `fd`.<br>
  Полное имя: `find`.<br>
  Аргументы: `std::string`, `char`.<br>
  Возвращаемое значение: `std::size_t` (номер символа в строке).<br>
  В случае, если символ не нашелся, нужно выбросить исключение.

- Определение длины строки.<br>
  Короткое имя: `len`.<br>
  Полное имя: `length`.<br>
  Аргументы: `std::string`.<br>
  Возвращаемое значение: `std::size_t`.

- Получение символа по индексу.<br>
  Короткое имя: `at`.<br>
  Полное имя: `atindex`.<br>
  Аргументы: `std::string`, `std::size_t`.<br>
  Возвращаемое значение: `char`.<br>
  При превышении индексом длины строки нужно выбросить исключение.

### Приложение `calculator`

Необходимо добавить в калькулятор команды для работы
с комплексными числами:

- Сложение.<br>
  Короткое имя: `ca`.<br>
  Полное имя: `cadd`.<br>
  Аргументы: комплексное число, комплексное число.<br>
  Возвращаемое значение: комплексное число.

- Умножение.<br>
  Короткое имя: `cm`.<br>
  Полное имя: `cmul`.<br>
  Аргументы: комплексное число, комплексное число.<br>
  Возвращаемое значение: комплексное число.

- Модуль.<br>
  Короткое имя: `abs`.<br>
  Полное имя: `cabs`.<br>
  Аргументы: комплексное число.<br>
  Возвращаемое значение: `float`.

Комплексное число задается одним токеном в одной из форм
`a`, `a+bi`, `a-bi`, `bi`, `-bi`,
где `a` и `b` &mdash; действительные числа
(в том числе в экспоненциальной форме).
Токен должен быть использован целиком, то есть
`1++2i`, `1+-2i`, `1j`, `i2`, `1+2` &mdash; это
ошибки разбора, которые должны приводить к исключению.

Тип комплексного числа и парсер для него допустимо реализовать
самостоятельно либо использовать `std::complex`
из стандартной библиотеки.
При собственном типе потребуется определить `operator<<`
для вывода результата;
формат вывода &mdash; `(a,b)`, например, `(4,-2)`.

Пример работы доработанного калькулятора:

```
calc> cadd 1+2i 3-4i
(4,-2)
calc> cmul 1+2i 3+4i
(-5,10)
calc> abs 3+4i
5
calc> ca 1++2i 0
Error: failed to parse complex from '1++2i'
calc> exit
```

По желанию можно написать юнит-тесты.
